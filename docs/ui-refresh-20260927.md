# 小屋视觉改版 · 2026-09-27

## 设计

参考 Apple 中国官网 https://www.apple.com.cn/ 的分区展示方式，使用更清楚的标题层级、大幅角色场景、留白及少量主题色。保留小屋的黄色角色与情侣生活主题，不复制 Apple 品牌素材。

- 首页：主欢迎区、日常概览、回忆／愿望／足迹探索卡片、心情与生活记录。
- 导航：桌面主导航、横向全功能入口、手机底部导航，后台增加当前页面指示。
- 功能主题：签到／用餐；相册／拍照；商店、兑换和惊喜／礼物；日历／爱心日历；故事和日报／书写；足迹／旅行；钱包和成就／庆祝；个人中心／休息。
- 愿望和足迹：桌面编辑区随滚动保持可见，手机优先展示已有记录。
- 心情：七档独立生成的完整角色图，取消圆形裁脸；颜色、文案、选中反馈随选择变化，支持方向键和 Home／End；最多选择八个标签。

## 素材与动画

使用内置 image_gen，以原有角色图为身份参考生成六个功能动作和七个心情。原图保留，新素材使用版本化路径。提示词与生成文件名见 `visual-assets-20260927.json`。

- `public/nailong/features-v3.webp`：六格功能角色图集。
- `public/nailong/moods-v3/*.webp`：全部七档心情。
- 新图集与心情素材合计约 280 KB；PNG 生成原件保留在生成工具输出目录。
- 动画是 CSS 驱动的轻摆、呼吸、抬升、步行动作、书写摇摆及庆祝跳动，不是骨骼动画或逐帧视频。
- 页面／卡片入场、照片预览显现、心情切换、选项悬停、按钮待提交、日历选择、进度条与徽章反馈均有动效。
- 装饰动画有限次播放，所有动效遵循 `prefers-reduced-motion`，内容不会依赖动画显示。
